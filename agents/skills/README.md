# S1-GRiTS Agent skills / Agent 使用入口

These files accompany the S1-GRiTS **4.0.0 candidate**. They are available in this
checkout and the source distribution, separately from the Python wheel. A source
version does not mean that version has already been published to PyPI.

| Task / 任务 | Entry / 入口 |
| --- | --- |
| Configure, build, inspect or resume a Cube / 配置、构建、检查与续跑 | [s1grits-cube](s1grits-cube/SKILL.md) |
| Read existing products, derive or analyze / 读取已有产品、派生与分析 | [s1grits-analysis](s1grits-analysis/SKILL.md) |
| Hand off an existing dataset / 已有数据交接 | [s1-data-handoff](s1-data-handoff/SKILL.md) |

## Use / 使用

Obtain a checkout or source archive matching the software version you intend to
use. Point your Agent to the selected `SKILL.md` and the matching repository docs;
it can follow the instructions without automatic skill discovery. If your Agent
supports registered skills, register that path using its own configuration.
These files do not install Python dependencies or modify Agent settings.

例如，在项目中对 Agent 说明：

> 读取 `agents/skills/s1grits-analysis/SKILL.md`，按已有 Cube 小样本教程执行，
> 保存实际命令并检查输出数值。

先核对解释器、实际导入位置与所需命令 `--help`。生产 YAML 保存配置；skill 组织
已有 CLI/Python 调用。完整流程见[Agent 指南](../../docs/agent_workflows_ZH.md)。
已使用规范源的本工作区无需再次安装这些发布副本。

## Maintain / 维护

`s1grits-cube/` and `s1grits-analysis/` are **generated exports: do not edit them**.
Their sole editable source is the maintainer workspace's `.agents/skills/` tree.
[manifest.json](manifest.json) records the compatible package version and the
SHA-256 of each exported source file. `s1-data-handoff` remains the repository's
existing reference to the public handoff guide and is not generated by this tool.

From the repository root, regenerate after changing the canonical skill or the
package version:

```sh
python tools/export_agent_skills.py --source-root /path/to/workspace/.agents/skills
```

Commit the exports and manifest together. The exporter copies only these two
skills and leaves other files in this directory alone. Release staging is not an
additional editable source. There are no domain-specific application skills here.
